# 学生ロケット シミュレーター

モデルロケット〜学生ハイパワーロケットの飛行をブラウザで計算する静的 Web アプリ（PWA）。

## できること
- **機体設計**: ノーズ形状・寸法・ボートテール・フィン（枚数/形状）・質量/重心・バラスト
- **モーター**: プリセット（Estes C6 〜 L クラス、学生ハイブリッド例。いずれも近似値）、パラメトリック推力曲線、RASP `.eng` / `t,F` 表の貼り付け
- **質量モデル**: 機体＋固体モーター、またはハイブリッド（乾燥質量・酸化剤・燃料グレインの質量と重心、タンク口金への重心移動）
- **回収系**: 1段目（頂点検知・点火/作動終了タイマー・冗長タイマー）＋2段目（高度・タイマー）、パラは直径×Cd か降下終端速度で指定、ペイロード放出
- **諸元表**: 射場審査の「団体入力シート」形式 xlsx を読込・書出し（シートに無い項目は「シミュレータ追加諸元」シートに補完）。Debug 諸元のプリセット付き
- **落下分散**: 風速×風向スイープで弾道落下／減速落下／ペイロードの着地点を地図に描き、許可域・禁止域から風向別の許容風速（GO/NOGO 表）を出す。CSV / KML 出力
- **環境**: 射点緯度経度・標高・気温（ISA）、磁気偏角（方位・風向の磁北/真北基準）、ランチャー長・射角・方位、基準高さ付きべき法則の風＋乱流、着地面（射点/海面）
- **結果**: 頂点高度・最大速度/マッハ・加速度・ランチクリア速度・安定余裕・開傘速度・着地速度/距離、警告表示
- **3D ビュー**: 機体形状を立体化して軌跡上を再生。カメラは自由視点／追従／射点から見上げ／機上カメラ
- **可視化**: 機体図（CG/CP）、側面/上面の軌跡と再生、各種時系列グラフ
- **解析**: モンテカルロ着地分散（95% 楕円）、任意パラメータの掃引
- 設定の JSON 保存/読込、飛行データの CSV 出力。設定は自動でブラウザに保存

## モデル
- 6 自由度（並進3＋ピッチ/ヨー＋ロール、ジャイロ連成）の剛体、RK4 積分（硬い入力は自動サブステップ）
- 空力は Barrowman 法（CNα・CP・減衰）か、諸元表の値（CP・軸力係数・CNα・Cmq・Clp、マッハ表 CSV も可）を直接使う
- Cd は Mandell 系簡易式で形状から推定（手入力も可）、遷音速の抗力増加は近似。ノズル出口径から高度による圧力推力を補正
- 仕様（実装契約）は `docs/spec-v2.md`

あくまで教育・設計検討用です。実際の打上げは OpenRocket 等と実測値で確認してください。

## 起動
```
python -m http.server 8775
```
→ http://localhost:8775

## テスト
ヘッドレス Chrome で実行（`bash test/headless.sh <URL|ファイル>`）:
- `test/physics-test.html`（物理・審査値の検算）, `test/specsheet-test.html`, `test/dispersion-test.html`, `test/app-smoke.html`（結合）
